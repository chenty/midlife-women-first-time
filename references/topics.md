# 选题引擎

## 一、唯一判据

> **这件事，她家里会不会有人反对？**

会 → 写。不会 → 不写。

这类文章的张力，来自"一个人想做点什么"和"周围人不理解"之间那点摩擦。**没有被反对过的事，写出来就是流水账。**

- "她今年学会了用手机支付" → 没人反对 ❌
- "她 45 岁去考驾照，老公说这钱够买台洗衣机" → 有摩擦 ✅

---

## 二、选题公式

> **【年龄+身份】的她，去做【一件小事】，【某个身边人】问她：【一句误解】**

示例：
- 四十岁的她，去考驾照，教练问她："家里要买车啊？"
- 四十五岁的她，去报了游泳班，同事问她："是不是身体出问题了？"
- 五十岁的她，一个人去吃了顿火锅，服务员问她："几位？"

**三个零件：标签 + 小事 + 一句外部的误解。** 外部误解比作者的观点好用一万倍——它替读者问出了那句话，而整篇文章就是回答。

---

## 三、四象限（长期可循环，不重复）

### A · 第一次
"这年纪学它干啥"的事：考驾照 / 学游泳 / 学英语 / 学电动车 / 学用电脑 / 报老年大学 / 学做直播
→ **必备**：年龄 + 一句"这年纪学它干啥"的质疑

### B · 自己的钱
第一次把钱花在只对自己有用的地方：买一件超过 500 块的衣服 / 自己去做个体检 / 一个人吃一顿贵的 / 给自己买保险
→ **必备**："这钱不如给家里添件东西"这句反对

### C · 身体
剪短发 / 染头发 / 减重 / 去健身房 / 拒绝一场不想去的饭局
→ **身体是最不能替别人活的东西，张力天然存在**

### D · 时间
每周请半天假去练车 / 一个人看一场电影 / 不接电话的两小时 / 独自旅行三天 / 第一次说"这次我不去"
→ **时间比钱更难拿，因为"你闲着也是闲着"是最普遍的反对**

## 五、找人优先级

1. 你正在经历的场景里的陌生人（驾校同车人、体检排队、健身房隔壁）
2. 你工作里见过的人（十几年的基层工作 = 巨大的素材库）
3. 亲戚/邻居/同学群里的那个"不太一样"的人
4. 读者留言里的人（私信，征得同意——转化关系最好的方式）

**找人的唯一标准：她能说出一句让你愣一下的话。**

那句让你愣一下的话，就是这篇文章的题眼。

---

## 六、避坑

- **别选名人、别选新闻里的人。** 力量来自"我认识她"，不是"我在网上看到她"。
- **别选太惨的人。** 主角不能是受害者，她是"日子还行，但想给自己要点什么"的人。惨会偷走她的主动性。
- **一篇只写一个人。** 写两个人就散了。
- **别为了赶上发稿而降低素材门槛。** 宁可晚三天发文，也不要发一篇编的。
