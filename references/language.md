# 语言库：金句 / 标题 / 结尾提问

---

# 一、金句句式（6 个模板，套着填）

**密度要求：每 300 字一句，全篇不少于 4 句。** 金句不是点缀，是密度铺出来的。

## 1. 账本式 ⭐最强

> **【A】都叫【好词】，轮到【B】，才叫【坏词】。**

- "人这一辈子，给家里花的钱都叫应该，轮到给自己花，才叫浪费。"
- "给孩子花的时间和钱都叫本分，轮到给自己，就成了瞎折腾。"
- "替别人早起的二十年都叫贤惠，轮到给自己早起一天，才叫不顾家。"

**为什么强**：它不稳定地颠倒了所有人默认的账本，但没人能反驳。最容易被截图转发的一类。

## 2. 归属式

> **【东西】是她的，【细节】永远是别人用过的那个。**

- "家里那台车，副驾是她的，座椅永远是别人坐完的那个位置。"
- "厨房是她的，可那口锅的口味，一直是别人的。"

## 3. 时间对比式

> **【做了 N 年某事】，头一回知道【一个常识】。**

- "坐了二十年车，头一回知道，这个位子是能按自己的腿长调的。"
- "做了二十年饭，头一回知道，菜是可以按自己的口味放盐的。"

## 4. 反面定义式

> **她不是要【大词】，她要【小东西】。**

- "她不是要独立，她要的是出门不用看谁的时间表。"
- "她不是要自由，她要的是能自己把车停进那个车位。"

## 5. 微小定量式

> **就【那么几】【单位】。**

- "就是把座椅往前调那么两格。"
- "就是每周三下午那三个小时。"

## 6. 动作收束式（用在最后一句）

> **【物件】在她手里，【后半句】，她【动词】。**

- "方向盘在她手里，前面的路，她自己打方向。"

---

## 三条纪律

1. **一篇 3–5 句用粗体，超过 5 处就贬值。** 原爆款用了 5 处。
2. **金句必须从细节里长出来。** "座椅"出现两回之后，那句归属式才有分量。没有铺垫的金句是空话。
3. **不要在段首放金句。** 放段末，让它砸下来。

# 二、标题公式（5 个模板）

## 1. 第三方误解式 ⭐首选

> **【年龄+身份】的她去【做的事】，【某人】问她：【一句误解】**

- ✅ "四十岁去考驾照，教练问她是不是家里要买车"
- 例："四十六岁去报游泳班，前台问她是不是给孩子报的"

**为什么首选**：标题里没有观点，只有一个"为什么这么问"的悬念。停留 1 秒就会点开。

## 2. 定量对比式
> "她坐了二十年副驾，今年才坐上驾驶座"

## 3. 物件式
> "副驾的座椅，永远是别人坐完的那个位置"

## 4. 数字式
> "她考了三回科二，第三回才过"

## 5. 一句话原话式
> "'我就想握一回方向盘'：一个四十岁女人去考驾照"

---

## 禁用词（出现就重写）

| 禁用 | 原因 |
|---|---|
| 觉醒 / 独立 / 重生 / 逆袭 | 结论型，读者不用点开就知道全文说什么 |
| 中年女人都该 / 所有女人 | 说教感，招反感 |
| 我决定 / 我终于 | 把旁观者写成主角，破坏视角标识 |
| 破防 / 泪目 / 全网 | 廉价情绪词，拉低可信度 |
| 疑问式（"四十岁学车，来得及吗？"） | 像鸡汤号，且答案已在标题里给出 |

**测试法**：念给一个 45 岁女性朋友听，只问"你想不想知道后面怎么了"。她说"大概能猜到"→ 重写。

# 三、结尾提问库

## 铁律

> **问经历，不问观点。** "你有没有……" ✅ ／ "你怎么看……" ❌

观点题要读者思考+组织语言，成本高；经历题脑子里已有现成答案，成本为零。

## 五个模板

1. **存货式**（最好用）：「你心里是不是也有一件想学、又怕没用的事？」
2. **位置式**：「你有没有哪件事，本来是自己的位置，一直让给别人坐？」
3. **时间式**：「你上一次一个人出门，是什么时候？」
4. **钱式**：「你上一次给自己花钱，没跟任何人报备，是什么时候？」
5. **未完成式**：「有没有一件事，你报了名，到现在还没开始？」

## 提问之后必须做的两件事

1. **立刻结束。** 后面不加解释、不加鼓励、不加引导关注。
2. **试答一遍。** 答案是"嗯……让我想想" → 换题；答案是"有啊，我一直想学游泳" → 对了。

# 四、还差一点怎么办（应急三招）

| 症状 | 解药 |
|---|---|
| 太顺了，不像真的 | 去⑤狼狈段再加一个"不体面"的细节 |
| 太满了，读者插不进话 | 删掉最后一段的道理，只留动作 |
| 太平了，转发不出去 | 找那句能改写的话，改成账本式 |
