# 细节与意象

## 一、素材清单（3 + 1 + 1 + 1）

每篇必须采齐这六样，少两样以上不能动笔。

| # | 类型 | 要求 | 原爆款示例 |
|---|---|---|---|
| 1 | 可量化动作 A | 带数字的重复动作 | "调一下，坐一坐，再调一下"（三回） |
| 2 | 可量化动作 B | 带数字的失败 | "科二考了三回，前两回倒库压线" |
| 3 | 可量化动作 C | 带数字的生活细节 | "打第三个电话才约到，车费比平时贵多少" |
| 4 | 她自己的原话 | 一句，必须是原话不是转述 | "我就想握一回方向盘……不用被别人牵制" |
| 5 | 反对者的原话 | 公平、甚至听起来有道理 | "这钱够买台洗衣机……一个女人家逞什么能" |
| 6 | 一个锚点物件 | 能反复出现 | 座椅 |

---

## 二、怎么采（三种问法）

**不要问"你怎么想的"**，要问：

1. **"那天具体是怎么弄的？你从头说一遍。"**
   → 拿到动作和数字。人讲流程时会自动吐出细节。

2. **"最难的是哪一次？"**
   → 拿到狼狈段。这一问几乎必出金句。

3. **"你家里人怎么说？"**
   → 拿到反对者的原话。**记原话，不要记你的总结。**

**记录规范**：只记名词、动词、数字和原话。**不要记形容词。** 形容词是你回去再写的，细节错过了就永远没有了。

## 三、锚点物件清单（选一个，不要贪多）

好的锚点物件满足三条：**小、可重复、有"被安排"的意思。**

| 物件 | 能承载什么 | 适合的选题 |
|---|---|---|
| **座椅** ⭐最强 | 位置是被别人调好的 / 现在我自己调 | 学车、通勤、任何"让位"的事 |
| 方向盘 | 谁在决定方向 | 学车、旅行、做决定 |
| 钥匙 | 谁有权利启动 | 学车、开店、独自出门 |
| 后视镜 | 回看自己 / 别人眼里的她 | 结尾好用 |
| 一双鞋 | 走过的路 / 舍不舍得为自己买 | 买贵的东西、独自旅行 |
| 碗筷 | 一个人吃饭 / 谁先吃谁后吃 | 一个人吃饭、拒绝饭局 |
| 手机 | 不被找到的两小时 | 独处、退出群 |
| 存折/余额 | 她的钱是谁的 | 自己的钱 |
| 头发 | 剪掉的是谁的审美 | 剪短发、染发 |
| 门 | 出得去 / 进得来 | 独自出门、拒绝 |

**使用铁律：**
- 全文只选 **1 个**，最多 2 个
- 必须在 **①段出现一次、⑦段再出现一次**
- 出现时**只写动作，不解释含义**

> ✅「她把座椅往前调那么两格」
> ❌「座椅象征着她终于找到了自己的人生位置」（解释即死亡）

## 四、三种高级用法

### 1. 用动作代替情绪
> ❌ 她心里很不是滋味。 → ✅ 她摇头。
> ❌ 她感到前所未有的自由。 → ✅ 坐踏实了，才把钥匙拧开。

**规则：删掉所有"感到 / 觉得 / 心里"开头的句子。**

### 2. 用"算得清的小账"代替抒情
> ❌ 她觉得这一切都值得。 → ✅「车费比平时贵多少。」

**规则：情绪越强的地方，越要写一个具体的数字或物件。**

### 3. 用"不够体面"的细节建立信任

手心全是汗 / 歪歪扭扭挪出十几米 / 下车喝口水接着排号 / 被同车的小伙子笑 / 坐一下才让脚够得着踏板。

**规则：一篇里至少 2 个让她"不体面"的细节。** 全部体面的主角，读者不会认。

## 五、红线

| 红线 | 说明 |
|---|---|
| 不编 | 一个细节编了，整篇可信度都在赔 |
| 不美化 | 不要把"歪歪扭扭"改成"稳稳开出" |
| 不概括 | "她吃了很多苦"是概括；"考了三回"是细节 |
| 不挪用 | 别人身上的细节不能安到她身上 |
| 不写隐私 | 住址、孩子学校、单位全名一律虚化 |
| 要征得同意 | 写真人前问一句"我能写你吗" |

**素材不够时**：宁可输出「补采清单」让用户回去问，也不要填空。这是本技能的硬规则。
