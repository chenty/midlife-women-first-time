# 中年女人的第一次

一个可复用的写作技能包（Agent Skill）：把一个 40+ 普通女性的真实素材，写成一篇**读者看完必须说"我也是"**的中文公众号推文。

不是通用写作提示词。它带着一套**验收标准**：写完之后用脚本跑 17 项机械质检，不过就不许发。

---

## 这套东西解决什么问题

写给 40+ 女性的号，最容易掉进两个坑：

- **写成了励志文**——她终于做到了，读者点个赞就走了，不会说话。
- **写成了自我感动**——作者在抒情，人物在做道具。

这个技能的解法是三条硬约束，写进 `SKILL.md` 的执行流程里：

1. **白描，不判断。** 只写看见的。删掉所有"感到 / 觉得 / 心里"。
2. **不给圆满结局。** 结尾必须留白，`check_draft.py` 会扫结尾 400 字里的成功向表达。
3. **结尾不加引导语。** 不要求点赞、不要求在看、不上价值，只把话筒递给读者一问。

用 HTTPS：

### 方式二：下载 zip

把仓库打包下载，解压后放在 `~/.claude/skills/` 下，确保目录名是 `midlife-women-first-time`、里面直接是 `SKILL.md`。

### 在 Claude 里用

放好之后，直接说要做什么即可，技能靠 `SKILL.md` 里的 description 自动触发：

- 「写一篇稿子，素材是……」
- 「这篇帮我按中年女人第一次的文体改一下」
- 「给这批选题排个顺序」

### 在 Arena / 其他 Agent 里用

把 `SKILL.md` 交给模型当系统提示或首轮上下文，其余 `references/` 按需读取。所有文件都是**自包含**的，不依赖任何仓库外的资料。

## 验证安装成功

```bash
cd ~/.claude/skills/midlife-women-first-time

# 范本应当 17 项全过
python3 scripts/check_draft.py assets/sample_pass.md --object 方向盘

# 期望输出：结果：❌ 0 失败 · ⚠️ 0 警告 · ✅ 17 通过
```

`--object` 是这篇的**锚点物件**（贯穿首尾、结尾含义发生变化的那件东西）。范本用的锚点是「方向盘」，不是标题里的「驾照」——锚点物件不必是标题词，它必须是正文里真的反复出现、并且到结尾被重新理解的那个东西。

跑不通就先确认 `python3` 可用（只用标准库，无需 pip 安装任何东西）。

## 17 项质检里，最该在意的几项

| 项 | 判据 | 为什么 |
| --- | --- | --- |
| 锚点物件闭环 | 同一物件首现 ≤35%、末现 ≥70% | 首尾两次出现，**含义必须变了**，否则不是闭环是重复 |
| 结局是否圆满 | 结尾 400 字内无成功向表达，且前面有否定词 | 这是这套文体最致命的一项，圆满了就变爽文 |
| 结尾引导语 | 无「点赞/在看/关注/转发」 | 零引导是这个号的人格 |
| 心理描写 | 无「感到/觉得/心里」 | 行动不写心 |
| 金句密度 | ≥4 句，且必须含**账本式** | 金句是读者要截图的那句，没有就没人转 |
| 语言节奏 | 平均句 20–24 字；≤12 字 ≤45%；**平均段 ≥30 字；一句成段 ≤28%** | 短句连敲会从白描变警句体；一句一段读起来像敲桌子 |

**关于段落那条，是踩了坑才加的。** 早期版本只量句子不量段落，有一篇稿子句子层全部达标、读起来还是碎的——因为一句一段占了 35%。所以现在的顺序是：**先并段落，再谈句子。**

## 已知的边界

- 脚本查得出**形**，查不出**发现**。四问（发现是什么 / 材料凭什么放一起 / 意义怎么变 / 结尾如何照亮开头）得自己答，答不上就别发。
- `check_draft.py` 的关键词表是**症状表**，不是词表。比如叙述他人数据时会撞到「点赞」，这是误报，改文案不要改工具。
- 这套文体默认**单篇独立**。连发两篇入口相同（比如都用陈述开场）会立刻露馅，`check_variation.py` 就是干这个的。
