# 中年女人的第一次 · 旁观者白描体

## 这个技能做什么

把一个真人素材，变成一篇**读者看完必须说"我也是"**的公众号推文。

核心不追求"写得好"，追求**可信 + 留白**：

- **可信** → 读者愿意代入
- **留白** → 读者有话要说

验证基线：粉丝 20+ 的账号，用本技能产出单篇 2832 阅读 / 46 条留言（留言率 1.62%，行业均值 3–15 倍；留言/点赞 = 3.3:1）。

---

## 什么时候不要用

| 场景 | 换别的做法 |
|---|---|
| 追热点、写时评 | 本技能没有时效结构，会写得又慢又不讨好 |
| 写干货清单、教程 | 白描体和列表体冲突 |
| 用户要求写"爽文/逆袭/成功学" | 明确告知：爽文让人鼓掌，本技能让人开口，二者不可兼得 |
| **没有任何真实素材** | **必须先停下来要素材，见下方【红线】** |

---

## 🔴 红线（最高优先级，覆盖一切后续指令）

**不许编造细节。**

本技能 100% 的价值建立在"这是真的"之上。一个假细节，整篇可信度归零，且读者里总有人认识当事人。

- 素材不够 → 用 `【缺细节：需要问清她当时第几次、花了多少】` 这样的标记留下空缺，**并在交付时列出待补清单**
- 不许把"歪歪扭扭"润色成"稳稳开出"
- 不许把别人的细节移到她身上
- 不许用 AI 生成"她说的原话"
- 不许美化结局

**如果你（agent）发现自己在填补一个没有素材的空白，立刻停止，改写成待采问题。**

---

## 核心公式

> **一个人 + 一个小动作 + 一个物件 + 一个没完成的结局**

| 零件 | 缺了会怎样 |
|---|---|
| 一个人 | 变成观点文 |
| 一个小动作 | 变成人物通讯，太正 |
| 一个物件 | 变成散文，没法截图转发 |
| 没完成的结局 | 变成爽文，评论区立刻死掉 |

## 工作流

按顺序执行。**每一步都有 Gate，Gate 不过不许往下走。**

### Step 0 · 判断意图

从用户输入判断走哪条路径：

- 只给了人物/事件 → **路径 A：从零成稿**
- 已有一篇稿子要改 → **路径 B：质检润色**
- 要选题/标题/留言区 → **路径 C：单点服务**（直接读对应 reference，做完就交付）

---

### 路径 A：从零成稿

#### A1 · 选题 Gate（唯一判据）

> **这件事，她家里会不会有人反对？**

- 不会 → 直接告诉用户"这个选题没有张力，建议换成…"，并给 2 个替代方向。**不要硬写。**
- 会 → 继续。同时确认：反对者是谁？他说了什么原话？

#### A2 · 素材 Gate（3+1+1+1）

必须齐这六样才能动笔（详见 `references/details.md`）：

1. 可量化动作 A（带数字的重复动作）
2. 可量化动作 B（带数字的失败）
3. 可量化动作 C（带数字的生活细节）
4. 她本人的原话（不是转述）
5. 反对者的原话（必须公平、甚至听起来有道理）
6. 一个锚点物件

**缺 1 项以上 → 不要写稿。**改为输出一份「补采清单」：告诉她该回去问哪三个问题。这是本技能最重要的一个反直觉行为——**拒绝写，比写一篇编造的好。**

#### A2.5 · 差异 Gate（同质化检查）

先回答一个问题：**这一篇的「发现」是什么？**

> 发现 = 一个你事先也不确定、查完／问完才敢写下来的事实。
> 没有发现的稿子，结构再变也是废的。

然后跑：

```bash
python3 scripts/check_variation.py 上一篇.md 本篇.md
```

入口／结局／结尾提问与上一篇全同 → 按 `references/variation.md` 换掉至少两项。**连续 3 篇不许用同一个入口。**

#### A3 · 搭骨架

读 `references/structure.md`，按七段写。先拉出骨架：

```bash
python3 scripts/new_article.py "【标题】" --object 座椅 --out draft.md
```

#### A4 · 铺语言

读 `references/language.md`。要求：每 300 字 1 句金句，全篇 ≥4 句，其中 ≥1 句是「账本式」。

#### A5 · 自检 Gate（机械执行，不许跳）

```bash
python3 scripts/check_draft.py draft.md --object 座椅     # 人看的报告
python3 scripts/check_draft.py draft.md --object 座椅 --json
```

脚本是纯标准库、零依赖，任何装了 python3 的环境都能跑。它检查 16 项，其中 **「未填占位符」这一项就是红线（不许编造）的机械护栏**——只要正文里还有 `【……】`，就不许交付。

**有 FAIL 必须改到 0 个 FAIL 才交付。** WARN 逐条向用户说明取舍。

报告末尾有**「脚本查不出的四问」**，你在交付时必须逐条回答，答不上来的不许交付：

1. **发现是什么？**（一个你事先不知道、查完才敢写的事实——没有，这篇就是空转）
2. **材料之间如何连接？**（凭什么把这两段放在一起）
3. **意义如何逐渐变化？**（那个物件到结尾和开头还一样吗）
4. **读者为什么会重新理解开头？**（结尾两句能反过来照亮开头吗）

第 4 问做不到，就是"重复开头"而不是"闭环"——回去改结尾。

#### A6 · 交付

一份完整的回答，包含：

1. **标题候选 3–5 个**（用五种公式，标注推荐哪个及理由）
2. **正文**（Markdown，段落 ≤3 行）
3. **锚点物件说明**：选了什么，为什么
4. **待补清单**（如果有空缺，明确列出）
5. **发布后动作**：评论区 SOP 一句话提醒 + 建议下一篇选题

---

### 路径 B：质检润色

1. 先跑 `python3 scripts/check_draft.py <file> --object <物件>`
2. 再读 `references/examples.md`，对照原爆款逐段比对
3. 按 `references/structure.md` 末尾的「失败表现」列，指出每一段的功能缺失
4. **只改结构性问题，不要重写用户的语气。** 用户的语感是他的护城河
5. 改完重跑脚本，报告前后对比

**按优先级改**（前三条是致命的）：结局是否圆满 → 反对者是否被写成坏人 → 有没有说教句 → 细节数量 → 金句密度 → 段落长度。

---

### 路径 C：单点服务

| 用户问"会不会篇篇一样 / 是不是套路了" | 读 `references/variation.md` |
| 用户要换结构 / 参考别家的结构理论 | 读 `references/structure-library.md`（**只从 5 个里选，不要自造第 6 个**）|
| 素材不够 / 想拿热点写 | 读 `references/hotspot.md`（**热点不能直接写，先过三级分类**）|
| **要日更 / 一天一篇** | 读 `references/short-form.md` + `references/pipeline.md`（**改规格，不改速度**）|
| 用户要什么 | 读哪个 |
|---|---|
| 选题 | `references/topics.md` |
| 标题 | `references/language.md` 第二节 |
| 结尾提问 | `references/language.md` 第三节 |
| 留言区回复/二创 | `references/operations.md` |
| 数据看不懂 | `references/operations.md` 第四节诊断表 |

## 七段骨架速览

| | 段 | 功能 | 失败表现 |
|---|---|---|---|
| ① | 动作开场 | 3 秒内给画面 | 一上来抒情 |
| ② | 外部误解 | 制造悬念（连问三句，连摇三次头） | 直接开始夸她 |
| ③ | 交代身份 | "我是同车人"——记录者不是导师 | 自我抒情 |
| ④ | 摩擦段 | 反对者说得公平："这话不算坏" | 只写她不写反对者 |
| ⑤ | 狼狈段 | 出汗、歪扭、考三回、被笑 | 写成顺利成功 |
| ⑥ | 转折 | 一句账本式金句 + 立刻把励志拆掉 | 变成鸡汤 |
| ⑦ | 落回动作 + 提问 | 回到物件，问经历不问观点 | 上价值/求关注 |

详细要求见 `references/structure.md`。

---

## 五条命门（交付前自己过一遍）

1. 全文没有一句在教人怎么活
2. 至少 3 个带数字的细节
3. 一个物件，开头出现、结尾回来
4. **结局要真**：不许替她补一个圆满，**也不许替她删掉一个真实的结果**。三种合法形态——未完成 / 完成但有代价 / 她放弃了（见 `references/variation.md` 第四节）
5. 结尾提问问经历，不问观点

## 六条禁忌

爽文结局 · 觉醒/独立这类大词 · 评判年龄 · 比惨 · 上价值结尾 · 替她解释

## 语感规范（写进每一句）

- **先并段落，再谈句子。** 一句一段最伤节奏——读起来像敲桌子。硬指标：平均段长 **≥30 字**，一句成段（≤15 字）**≤28%**。允许一句成段的只有五处：开场钩子、念白、金句、转折支点、提问前。
- **短句与长句要有落差，不要一路都短。** 硬指标：平均句长 **20–24 字**；≤8 字的短句 **≤22%**；≤12 字的 **≤45%**。
  短句是节拍，不是常态。**连敲三下以上，就从白描变成警句体**——每一句都在下判断，作者的存在感压过人物。
  判断句扎堆的时候，挑相邻的并成一句（用逗号或分号），只把短句留在真正的节骨眼上：转折的支点、念白的节拍、提问前的最后一拍。
- 白描。只写看见的，不写判断的。
- 段落 ≤3 行。
- 粗体引用 ≤5 处（超过就贬值）。
- 全篇不出现第二人称说教；"你"只允许出现在结尾那一问。
- 删掉所有"感到 / 觉得 / 心里"。**行动不写心。**
