# 反同质化手册

> 这份文件的存在，是因为本技能最大的失效模式不是"写得不好"，是**"每篇都一样好"**。
> 一个读者第一次读到"账本式金句"会被击中，第三次读到会想：这句是不是你每篇都备着。

---

## 一、先分清两种"一样"

| 类型 | 表现 | 读者反应 | 该不该变 |
|---|---|---|---|
| **母题一样** | 每篇都是"中年女人的第一次" | 这是品牌。她订阅的就是这个 | ❌ 不变 |
| **视角一样** | "我"永远是同车人／同事／旁观者 | 这是你的标识 | ❌ 不变 |
| **语感一样** | 短句、白描、段落 ≤3 行 | 这是你的声音 | ❌ 不变 |
| **结尾一样** | 每篇最后都把话筒递给读者 | 读者甚至期待 | ❌ 不变 |
| **入口一样** | 每篇都从"她把 xx 调一下，停一下"起 | 第 3 篇开始预判 | ✅ 必须变 |
| **行程一样** | 连问三句→连摇三次头→狼狈→账本金句→"我没夸她励志" | 第 2 篇就能背下来 | ✅ 必须变 |
| **发现一样** | 没有新发现，只是换个人再讲一遍 | 取关 | 🔴 致命 |

**分界线一句话：**

> **结构可预期 + 结论不可预测 = 舒适**
> **结构可预期 + 结论也可预测 = 套路**

读者从来不反对固定文体（《人生第一次》整季一个结构，《人物》杂志几十年一个文体）。读者反对的是"我提前知道你要说什么"。

## 二、真正致命的是「发现」，不是结构

第 2 篇《我数了那 46 条留言》之所以成立，**不是因为它的结构好**，是因为它有一个"只有数了才知道"的发现：

- 19 个人里 15 个主动报年龄（没人问她们）
- 50+2 的一把过，40 出头的一年没开始 → 年龄和进度无关

结构再变，如果没有这种发现，稿子还是废的。

### 每篇必须有一个「发现」

**发现 = 一个你自己事先也不确定、查完/问完才敢写下来的事实。**

三个稳定的来源：

| 来源 | 怎么找 | 例 |
|---|---|---|
| **数字** | 把素材数一遍，找反直觉的比例 | 15/19 报年龄；4/9 卡科三 |
| **原话** | 找一个她说的、和她的处境对不上的句子 | "用不用得上无所谓，但是得会" |
| **反差** | 两个人的进度／年龄／家境和预期相反 | 50+2 一把过 vs 40 出头没开始 |

**写作顺序要反过来：先有发现，再选结构。** 不是"我要写七段，找个人填"，是"我发现了这件事，用什么方式说出来最不肉麻"。

## 三、入口轮换（6 种，连续 3 篇不许重复）

| # | 入口 | 长相 | 已用 |
|---|---|---|---|
| 1 | 动作三拍 | 她把座椅往前调，调一下，坐一坐，再调一下 | 第 1 篇 |
| 2 | 数字先行 | 那 46 条留言，我从头看了一遍 | 第 2 篇 |
| 3 | 一句原话 | "学得慢才赚。"她在留言里写 | |
| 4 | 场景声音／气味 | 练车场七点就有人在喊号 | |
| 5 | 别人的一句判断 | 教练说，这年纪来学车的，十个有九个是家里要用 | |
| 6 | 物件的状态 | 副驾的座椅，还停在她老公的位置上 | |

> 入口决定读者要不要读第二句。同一个入口用三次，等于告诉读者"这篇我看过了"。

## 四、结局的三种合法形态 ⭐重要修正

原技能写的是「结局不能圆满」。**那是从 1 篇样本里提炼出来的过度规则**，会造成两个后果：一是套路化，二是**违反它自己的红线（不许编）**——真实世界里她有时真的考过了、真的买了车。硬把成功改写成不圆满，就是编。

**修正后的规则：**

> **不许替她补一个圆满，也不许替她删掉一个真实的结果。**

| 形态 | 长相 | 情绪落点 |
|---|---|---|
| **A · 未完成** | 她还卡在科三，车也没买，学出来用不用得上不知道 | 我也一样 → 留言 |
| **B · 完成了但有代价** | 拿到了，也确实开了，但那一年里她请了多少次假、被笑了多少回 | 值不值 → 留言 |
| **C · 她放弃了** | 考到科二就没再去，报名费作废，她说算了 | 沉默 → 最多的留言 |

**三篇之内必须出现 B 或 C。**

**C 是被严重低估的一种，也是最能防套路的。** 真实世界里，放弃的人比坚持的人多；一个账号如果只写坚持下来的人，它的真实度会一点点漏光。而且——"她后来没考了"这句话，比任何励志结尾都更让人想说话。

## 五、金句轮换

现在的技能把「账本式金句 + ⑥段段末」做成了固定动作。**这是最容易看出来的地方。**

| 维度 | 轮换方式 |
|---|---|
| **位置** | 段末（默认）／段首／让她自己在对话里说出来／不放 |
| **句式** | 三篇之内最多用一次账本式；归属式、时间对比式、反面定义式轮着来 |
| **数量** | 允许"零金句篇"——全靠细节，让读者自己得出结论 |

**"零金句篇"是最防套路的，也是最快的信任建立方式。** 一篇里全是具体的事，一句漂亮话都没有，读者反而会替你把那句话说出来——然后写在评论里。**读者替你总结，比你总结给他们看，强十倍。**

## 六、反对者不一定存在

技能默认"有一个反对的人（老公／教练／同事）"，因为第 1 篇有。但真实世界里有三种情况：

| 阻力类型 | 写法 | 例 |
|---|---|---|
| **有人反对** | 原写法：给反对者公平的说法 | "这钱够买台洗衣机" |
| **没人反对，也没人支持** | 最难写，但最普遍：沉默 | 全家不问，报名费她自己悄悄交的 |
| **最大的阻力是她自己** | 舍不得钱、怕丢脸、怕学了没用 | "用不用得上无所谓，但是得会" |

**第 2 和第 3 类写好了比第 1 类更扎人**，而且天然避开套路——因为它没有"反派"。

## 七、每 3 篇自查（跑一次）

- [ ] 三篇的入口类型是否重复？
- [ ] 是否三篇都有"连问三句、连摇三次头"？（有这个动作的，三篇最多一次）
- [ ] 是否三篇都用账本式收束？
- [ ] 是否三篇的结局都是"未完成"？（是 → 下一篇写 B 或 C）
- [ ] 三篇里有没有至少一个「只有问了/数了才知道」的发现？
- [ ] **节奏有没有跑偏？** 三篇的平均句长是否都在 20–24 字？有没有一篇的 ≤8 字短句超过 22%（读起来像在敲桌子）？
- [ ] **随机抽一段，你能猜出下一段写什么吗？能 → 重写。**

**机械检查**：

```bash
python3 scripts/check_variation.py 第1篇.md 第2篇.md 第3篇.md
```

## 八、终极外部测试（每 5 篇做一次）

把最近 5 篇的**开头两段 + 结尾两段**单独贴出来，去掉中间，发给一个老读者，只问一句：

> "这五篇里，你能凭开头猜出哪几篇的结尾？"

**她猜得出的篇数 ÷ 总篇数，就是你的套路率。超过 40% 就该改结构了。**

---

## 九、一句话总结

> 会让人腻的从来不是"你总写同一类人"，
> 是"你每篇都用同一种方式，告诉我同一件事"。
>
> **母题要窄，入口要散，发现要新，结局要真。**
