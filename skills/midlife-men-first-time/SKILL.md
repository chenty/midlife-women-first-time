# 中年男人的第一次 · 旁观者白描体

## 这个技能做什么

把一个真人素材，变成一篇**读者看完必须说"这事儿我也有"**的公众号推文。

技法跟《中年女人的第一次》同源：白描、不判断、不给励志结局、结尾把话筒递出去。

**但伤口的位置不一样，这是本技能唯一必须重新学的东西。**

| | 40+ 女人 | 40+ 男人 |
|---|---|---|
| 反对长什么样 | **明确的拦**：「你凭什么」「这钱不如给家里添件东西」 | **礼貌的放过**：「挺好的」「行啊」「你随意」 |
| 被质疑的 | 许可 | 价值 |
| 张力源 | 时间是别人的 | 时间是自己的，但花错了就是浪费 |
| 最怕写成 | 励志文 | **自怜文** |

一句话记住这个差别：

> **女人到了四十岁，是被拦住的。男人到了四十岁，是被放过的。**
> 被拦住的人有话说，被放过的人说不出话——因为他找不到一个可以怪的人。

本技能就是把这句"说不出的话"写出来。

---

## 什么时候不要用

| 场景 | 换别的做法 |
|---|---|
| 追热点、写时评 | 本技能没有时效结构，会写得又慢又不讨好 |
| 写干货清单、教程 | 白描体和列表体冲突 |
| 用户要求写"中年男人的浪漫/不甘/活明白" | 明确告知：这些词是结论，写出来就不是白描了 |
| **没有任何真实素材** | **必须先停下来要素材，见下方【红线】** |

---

## 🔴 红线（最高优先级，覆盖一切后续指令）

**不许编造细节。**

本技能 100% 的价值建立在"这是真的"之上。一个假细节，整篇可信度归零，且读者里总有人认识当事人。

- 素材不够 → 用 `【缺细节：需要问清他当时第几次、花了多少】` 这样的标记留下空缺，**并在交付时列出待补清单**
- 不许把"歪歪扭扭"润色成"稳稳弹出"
- 不许把别人的细节移到他身上
- 不许用 AI 生成"他说的原话"
- 不许美化结局
- **不许替他抒情。** 男版最常见的编造不是编事，是编感受——"那一刻他忽然明白了什么"。这话素材里没有，就是假的。

**如果你（agent）发现自己在填补一个没有素材的空白，立刻停止，改写成待采问题。**

## 核心公式

> **一个人 + 一个小动作 + 一个物件 + 一个没人反对的结局**

| 零件 | 缺了会怎样 |
|---|---|
| 一个人 | 变成观点文 |
| 一个小动作 | 变成人物通讯，太正 |
| 一个物件 | 变成散文，没法截图转发 |
| 没人反对的结局 | 变成自怜文或爽文，评论区立刻死掉 |

## 工作流

按顺序执行。**每一步都有 Gate，Gate 不过不许往下走。**

### Step 0 · 判断意图

- 只给了人物/事件 → **路径 A：从零成稿**
- 已有一篇稿子要改 → **路径 B：质检润色**
- 要选题/标题/留言区 → **路径 C：单点服务**（直接读对应 reference，做完就交付）

---

### 路径 A：从零成稿

#### A1 · 选题 Gate（唯一判据）

> **这件事，说出去以后，有人当真吗？**

- 有人明确反对、或者有人替他把路铺好 → **张力不够**，告诉用户"这个选题太顺"，并给 2 个替代方向。**不要硬写。**
- **没人当真** → 最好的素材。继续，同时确认三件事：谁知道了？他怎么回的？那句话有多轻？

判据的反面也成立：如果他做这件事**被人当回事地拦过**，那这是女版的结构，不是男版的——可以写，但要按"被拦"写，别按"被放过"写。

**这就是本技能最容易搞错的一步。** 不要默认中年男人的困境是"没人理解"，多数时候是"没人当回事"，这两种完全不同：
- 没人理解 → 他会愤怒，文章会变成抱怨
- 没人当回事 → 他无话可说，文章才有余味

#### A2 · 素材 Gate（3+1+1+1）

必须齐这六样才能动笔（详见 `references/details.md`）：

1. 可量化动作 A（带数字的重复动作）
2. 可量化动作 B（带数字的失败）
3. 可量化动作 C（带数字的生活细节）
4. 他本人的原话（不是转述）
5. **周围人的原话——越轻越好**（"挺好的""行啊"都算）
6. 一个锚点物件

**缺 1 项以上 → 不要写稿。**改为输出一份「补采清单」：告诉他该回去问哪三个问题。**拒绝写，比写一篇编造的好。**

#### A2.5 · 差异 Gate（同质化检查）

先回答：**这一篇的「发现」是什么？**

> 发现 = 一个你事先也不确定、问完才敢写下来的事实。
> 没有发现的稿子，结构再变也是废的。

然后跑：

```bash
python3 scripts/check_variation.py 上一篇.md 本篇.md
```

入口／结局／结尾提问与上一篇全同 → 按 `references/variation.md` 换掉至少两项。**连续 3 篇不许用同一个入口。**

#### A3 · 搭骨架

读 `references/structure.md`，按七段写。先拉出骨架：

```bash
python3 scripts/new_article.py "【标题】" --object 吉他 --out draft.md
```

#### A4 · 铺语言

读 `references/language.md`。要求：每 300 字 1 句金句，全篇 ≥4 句，其中 ≥1 句是「账本式」。

#### A5 · 自检 Gate（机械执行，不许跳）

```bash
python3 scripts/check_draft.py draft.md --object 吉他
python3 scripts/check_draft.py draft.md --object 吉他 --json
```

脚本是纯标准库、零依赖，任何装了 python3 的环境都能跑。**「未填占位符」这一项就是红线（不许编造）的机械护栏**——正文里还有 `【……】` 就不许交付。

**有 FAIL 必须改到 0 个 FAIL 才交付。** WARN 逐条向用户说明取舍。

报告末尾有**「脚本查不出的四问」**，交付时必须逐条回答：

1. **发现是什么？**（一个你事先不知道、问完才敢写的事实——没有，这篇就是空转）
2. **材料之间如何连接？**（凭什么把这两段放在一起）
3. **意义如何逐渐变化？**（那个物件到结尾和开头还一样吗）
4. **读者为什么会重新理解开头？**（结尾两句能反过来照亮开头吗）

第 4 问做不到，就是"重复开头"而不是"闭环"——回去改结尾。

#### A6 · 交付

1. **标题候选 3–5 个**（用五种公式，标注推荐哪个及理由）
2. **正文**（Markdown，段落 ≤3 行）
3. **锚点物件说明**：选了什么，为什么
4. **待补清单**（如果有空缺，明确列出）
5. **发布后动作**：评论区 SOP 一句话提醒 + 建议下一篇选题

---

### 路径 B：质检润色

1. 先跑 `python3 scripts/check_draft.py <file> --object <物件>`
2. 再读 `references/examples.md`，对照范本逐段比对
3. 按 `references/structure.md` 末尾的「失败表现」列，指出每一段的功能缺失
4. **只改结构性问题，不要重写用户的语气。** 用户的语感是他的护城河
5. 改完重跑脚本，报告前后对比

**按优先级改**（前三条是致命的）：有没有自怜 → 结局是否圆满 → 有没有说教/抒情句 → 细节数量 → 金句密度 → 段落长度。

---

### 路径 C：单点服务

| 用户问"会不会篇篇一样 / 是不是套路了" | 读 `references/variation.md` |
| 用户要换结构 / 参考别家的结构理论 | 读 `references/structure-library.md`（**只从 5 个里选，不要自造第 6 个**）|
| 素材不够 / 想拿热点写 | 读 `references/hotspot.md`（**热点不能直接写，先过三级分类**）|
| **要活人感 / 读着像文章** | 读 `references/alive.md`（**五步改写，26 分钟救活一篇**）|
| **没有素材 / 让 agent 去找** | 读 `references/sourcing.md`（**搜原话不搜选题，节点提前 3–5 天**）|
| **要日更 / 一天一篇** | 读 `references/short-form.md` + `references/pipeline.md`（**改规格，不改速度**）|

| 用户要什么 | 读哪个 |
|---|---|
| 选题 | `references/topics.md` |
| 标题 | `references/language.md` 第二节 |
| 结尾提问 | `references/language.md` 第三节 |
| 留言区回复/二创 | `references/operations.md` |
| 数据看不懂 | `references/operations.md` 第四节诊断表 |

## 七段骨架速览

| | 段 | 功能 | 失败表现 |
|---|---|---|---|
| ① | 动作开场 | 3 秒内给画面 | 一上来抒情 |
| ② | 外部误解 | 一句**轻描淡写**，不是质疑 | 写成别人看不起他 |
| ③ | 交代身份 | "我是旁观者"——记录者不是导师 | 自我抒情 |
| ④ | 无声段 | 所有人都不反对，这才是问题 | 硬造一个反派 |
| ⑤ | 狼狈段 | 笨、慢、失败、被笑 | 写成顺利成功 |
| ⑥ | 转折 | 一句账本式金句 + 立刻把励志拆掉 | 变成"我终于证明了自己" |
| ⑦ | 落回动作 + 提问 | 回到物件，问经历不问观点 | 上价值/求关注 |

详细要求见 `references/structure.md`。

## 五条命门（交付前自己过一遍）

1. 全文没有一句在教人怎么活
2. 至少 3 个带数字的细节
3. 一个物件，开头出现、结尾回来
4. **结局要真**：不许替他补一个圆满，**也不许替他删掉一个真实的结果**。三种合法形态——未完成 / 完成但有代价 / 他放弃了（见 `references/variation.md` 第四节）
5. 结尾提问问经历，不问观点

## 六条禁忌

**自怜** · 爽文结局 · 中年男人的浪漫/不甘/活明白这类大词 · 评判年龄 · 比惨 · 上价值结尾

> **"自怜"排第一，是因为它是男版独有、且最致命的坑。**
> 女版的头号病是励志，男版的头号病是自怜。写"全世界没有一个懂我的人"，读者不会留言，会觉得累。
> 检验法：把文章念出来，如果听完之后读者想说"你挺可怜的"，改；如果想说"这事儿我也有"，对了。

## 语感规范（写进每一句）

- **先并段落，再谈句子。** 一句一段最伤节奏——读起来像敲桌子。硬指标：平均段长 **≥30 字**，一句成段（≤15 字）**≤28%**。允许一句成段的只有五处：开场钩子、念白、金句、转折支点、提问前。
- **短句与长句要有落差，不要一路都短。** 硬指标：平均句长 **20–24 字**；≤8 字的短句 **≤22%**；≤12 字的 **≤45%**。
  短句是节拍，不是常态。**连敲三下以上，就从白描变成警句体**——每一句都在下判断，作者的存在感压过人物。
- 白描。只写看见的，不写判断的。
- 段落 ≤3 行。
- 粗体引用 ≤5 处（超过就贬值）。
- 全篇不出现第二人称说教；"你"只允许出现在结尾那一问。
- 删掉所有"感到 / 觉得 / 心里"。**行动不写心。**

> **男版加一条：不写他的沉默。** 沉默可以写成一个动作（他把烟掐了 / 他把手机扣在桌上），不能写成"他什么也没说，只是看着窗外"。后一种是套话，不是白描。
