# 语言库：金句 / 标题 / 结尾提问（男版）

---

# 一、金句句式（6 个模板，套着填）

**密度要求：每 300 字一句，全篇不少于 4 句。** 金句不是点缀，是密度铺出来的。

> **男版共用女版的 6 个句式，但"账本"记的不是一件事。**
> 女版算的账：谁的时间、谁的钱、谁的位置。
> 男版算的账：**什么时候叫应该，什么时候叫浪费。**
> 同一个动作，只要身份换一下，叫法就变了——这是中年男人最不服气、又最没办法反驳的一点。

## 1. 账本式 ⭐最强

> **【A】都叫【好词】，轮到【B】，才叫【坏词】。**

- "给客户陪到十一点都叫上进，准点回家一次，才叫不上进。"
- "给别人干活二十年都叫本分，轮到给自己买把吉他，才叫闲的。"
- "给家里换车都叫应该，给自己换双鞋，才叫乱花。"
- "孩子补课交八千都叫投资，自己报个班八百，才叫浪费。"

**为什么强**：它把所有人默认的账本翻过来，但没人能反驳。最容易被截图转发的一类。

## 2. 归属式

> **【东西】是我的，【细节】一直是别人的那个。**

- "这辆车是我买的，副驾的椅子，我一次没往后放过。"
- "房子是我装的，阳台那一半，一直堆着别人的东西。"
- "工资卡在我身上，密码我记不住，因为从来不用我记。"

## 3. 时间对比式

> **【做了 N 年某事】，头一回知道【一个常识】。**

- "开了二十年车，头一回知道，副驾的椅子能往后放。"
- "抽了十五年烟，头一回知道，早上起来嘴里能不发苦。"
- "上了二十三年班，头一回知道，周六上午是能空着的。"

## 4. 反面定义式

> **他不是要【大词】，他要的是【小东西】。**

- "他不是要热爱，他要的是每周六上午那两个小时。"
- "他不是想搞副业，他是想有一件事，跟这个家没关系。"
- "他不是要重新活一遍，他是想有一回，由自己说了算——哪怕只是一双鞋。"

## 5. 微小定量式

> **就【那么几】【单位】。**

- "就是每周六上午那两个小时。"
- "就是一双八百块的鞋。"
- "就是把第三根弦摁响那么一下。"

## 6. 动作收束式（用在最后一句之前）

> **【物件】在他手里，【后半句】，他【动词】。**

- "吉他搁在腿上，弦摁不住，他接着摁。"
- "跑鞋穿在脚上，走两步，又走两步。"

---

## 三条纪律

1. **一篇 3–5 句用粗体，超过 5 处就贬值。**
2. **金句必须从细节里长出来。** "吉他"出现两回之后，那句账本式才有分量。没有铺垫的金句是空话。
3. **不要在段首放金句。** 放段末，让它砸下来。

## 男版禁忌句式

| 不要写 | 因为 |
|---|---|
| "他终于明白，人这一辈子……" | 替人物总结 = 编感受，违反红线 |
| "成年人的世界，没有容易二字" | 陈词，谁都会写，等于没写 |
| "中年男人的崩溃是无声的" | 这就是自怜，是男版头号病 |
| "他不是不想，是不敢" | 这是替读者下判断，白描里不许有 |

# 二、标题公式（5 个模板）

## 1. 轻描淡写式 ⭐首选

> **【年龄+身份】的他去【做的事】，【某人】听完说："【一句轻】"**

- ✅ "四十三岁去报吉他班，老婆说：挺好的，别耽误接孩子"
- 例："四十五岁想一个人去看场球，同事说：行啊，你还有这精神"
- 例："四十岁给自己买了双八百块的鞋，他妈说：你又不跑步"

**为什么首选**：标题里没有观点、没有控诉，只有一句过分体贴的话。读者会停在那句话上——因为他也被人这么说过。

## 2. 定量对比式
> "他开了二十年车，今年第一次把副驾的椅子往后放"
> "抽了十五年烟，第四十二岁那年停了，办公室没人发现"

## 3. 物件式
> "那把吉他在阳台上放了四百天"
> "鞋柜最下面那双跑鞋，只穿过两次"

## 4. 数字式
> "四十岁学吉他，第一节他按不住第三根弦"
> "他去了六次健身房，第五次才敢进器械区"

## 5. 一句话原话式
> "'我就想有一件事，跟这个家没关系'：一个四十三岁男人去报吉他班"

## 禁用词（出现就重写）

| 禁用 | 原因 |
|---|---|
| 中年危机 / 不甘 / 活明白 / 体面 | 结论型，读者不用点开就知道全文说什么 |
| 中年男人的浪漫 | 一写就是自嗨，且立刻招笑 |
| 沉默 / 无声 / 扛 | 套路词，男版自怜的标准开头 |
| 我终于 / 我决定 | 把旁观者写成主角，破坏视角标识 |
| 破防 / 泪目 / 全网 | 廉价情绪词，拉低可信度 |
| 疑问式（"四十岁学吉他，还来得及吗？"） | 像鸡汤号，且答案已在标题里给出 |

**测试法**：念给一个 45 岁的男人听，只问"你想不想知道后面怎么了"。他说"大概能猜到"→ 重写。他说"这不就是我么"→ 过了。

# 三、结尾提问库

## 铁律

> **问经历，不问观点。** "你有没有……" ✅ ／ "你怎么看……" ❌

## 男版加一条铁律

> **问事，不问心。**

女版的提问可以轻轻碰到心里（"你心里是不是也有一件想学、又怕没用的事？"）。
男版不行——**两个男人之间问"你心里"，会立刻变成审问或者抬杠。** 所以要问一件他答得上来、而且能核对的事。

- ✅ "你上一次给自己花钱，是多少？"（有数字，他会去算）
- ❌ "你心里是不是也有很多没说出口的？"（他会关掉）

## 五个模板

1. **没人拦式** ⭐最狠：「你要做的那件事，有人反对过吗？」
   → 大多数人答"没有"。这一个"没有"，就是全篇的落点。
2. **时间式**：「你上一次一个人待着，是什么时候？」
3. **钱式**：「你上一次给自己花钱，没跟任何人说，是多少？」
4. **未完成式**：「你有没有一件事，准备了很久，从来没跟人提过？」
5. **物件式**：「你身上有没有一样东西，是你自己想买的？」

## 提问之后必须做的两件事

1. **立刻结束。** 后面不加解释、不加鼓励、不加引导关注。
2. **试答一遍。** 答案是"嗯……让我想想" → 换题；答案是"有啊，我一直想学游泳" → 对了。

# 四、还差一点怎么办（应急三招）

| 症状 | 解药 |
|---|---|
| 太顺了，不像真的 | 去⑤狼狈段再加一个"不体面"的细节：手抖、被笑、排队、贴创口贴 |
| 像在抱怨 / 像在自怜 | 删掉所有写他感受的句子，只留他做的事。**男版九成的自怜是靠删治好的** |
| 太平了，转发不出去 | 找那句能改写的话，改成账本式 |
