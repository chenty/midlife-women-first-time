# 选题引擎（男版）

## 一、唯一判据

> **这件事，说出去以后，有人当真吗？**

没人当真 → 写。有人当回事地拦 → 那是另一种结构，见第四节。

这类文章的张力，来自"一个人想做点什么"和"周围人礼貌地不接话"之间那点空。**被拦过的事有对手，被放过的事没有——所以更难写，也更好看。**

- "他四十岁想学吉他" → 老婆说"挺好的"，同事说"搞点爱好" ❌ 没有人当真，**这是最好的素材**
- "他四十岁要辞职去开店" → 全家开会反对 ✅ 可以写，但按"被拦"写，不是本技能的主场

**注意判据的方向：不要找"反对他的人"。** 男版找的是**那句最轻的回话**。因为中年男人真正的困境不是被打压，是**他做什么都没人管，于是他自己也开始觉得不该做**。

---

## 二、选题公式

> **【年龄+身份】的他，去做【一件小事】，【某个身边人】听完说：【一句轻描淡写】**

示例：
- 四十三岁的他，去报了个吉他班，老婆说："挺好的，别耽误接孩子。"
- 四十五岁的他，想一个人去看场球，同事说："行啊，你还有这精神。"
- 四十一岁的他，给自己买了双八百块的跑鞋，他妈说："你又不跑步。"
- 五十岁的他，学做菜，儿子说："爸，你玩这个?"

**三个零件：标签 + 小事 + 一句轻。** 女版要的是一句"误解"，男版要的是一句"没事儿"——**它不伤人，但它把事说小了。**

那句话必须满足两个条件：
1. 听起来是善意的，甚至是很体贴的
2. 听完之后，他自己都不好意思再提

> 全世界最难受的不是"你不行"，是"你随意"。

## 三、四象限（长期可循环，不重复）

### A · 第一次学点什么
"这年纪还学它干嘛"的事：学吉他／学游泳／考个证／学做饭／学剪辑／重新捡起英语
→ **必备**：一句"挺好的"式的回话

### B · 自己的钱
第一次把钱花在只对自己有用的地方：买一双好跑鞋／买套工具／报个班／买台相机／一个人吃顿贵的
→ **必备**："你又不缺这个"那句反对——注意，反对的理由往往是"你不需要"，不是"你不配"

### C · 身体
剪掉留了二十年的头发／去健身／戒烟／开始体检／不再喝酒
→ **身体是中年男人唯一还必须自己管的资产，张力天然存在**

### D · 时间
每周六上午空出来／准点下班／不接那个电话／一个人待两小时／不参加那场酒
→ **时间比钱更难拿，因为"你闲着也是闲着"是最普遍的反对**——注意这句女版也用，但用法不同：对女人是"你的时间不值钱"，对男人是"你反正也没别的事"

## 四、判断你拿到的是哪种素材

拿到素材先做这个分流，选错了整篇写歪：

| 素材长什么样 | 张力类型 | 怎么写 |
|---|---|---|
| 所有人都不反对，甚至鼓励 | **被放过**（男版主场） | 本篇第七节的全部技法 |
| 家里明确反对、吵过架 | 被拦住 | 可以写，但④段改成"反对者说得公平"（见 `structure.md`） |
| 他自己放弃了，没人知道 | 被放过·未完成态 | 最好的一种，结局天然合法 |
| 他做成了，但没人提 | 被放过·已完成态 | 次好，⑥段必须写"成了也没意思" |

**同一个人身上常常同时有两种。** 优先取"被放过"那一种——它更少见，也更能让人愣一下。

## 五、选题池（可直接排期）

- 四十岁，第一次进健身房，教练教他握哑铃，他问握多紧
- 四十二岁，把抽了十五年的烟停了，办公室没人发现
- 四十四岁，报名学游泳，站在浅水区不敢下去
- 四十五岁，第一次自己做饭，切到手指头，贴了创口贴继续切
- 四十七岁，买了一台相机，只拍楼下的树
- 四十八岁，重新背英语单词，背到 abandon 就停了
- 五十岁，把头发剃短了，第二天上班，没人说话
- 五十二岁，一个人去看了一场电影，散场时天还亮着
- 五十三岁，把周六上午空出来，去公园走路
- 五十五岁，第一次给自己买了双八百块的鞋，穿去上班

**排期原则**：四象限轮流，不要连着两个都在 A。

## 六、什么绝对不能选

| 不要写 | 因为 |
|---|---|
| 他一个人扛下全家、不喊累 | 这是表彰，不是故事。读者会点头，不会说话 |
| 他成功了、翻盘了、被认可了 | 爽文，评论区立刻死 |
| 他的爱好被老婆嫌弃、被孩子嘲笑 | 一骂家人，读者就开始站队，文章废掉 |
| 他"终于活明白了" | 这是结论，写出来就没有余味 |
| 他抑郁了、崩溃了、没人懂他 | 自怜。男版的头号禁区，见 `SKILL.md` 六条禁忌 |

**一句话检验**：这个故事如果讲给一桌中年男人听，他们是"哄"还是"静下来三秒"？哄 → 换题目。
