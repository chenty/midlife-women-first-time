# 细节与意象（男版）

## 一、素材清单（3 + 1 + 1 + 1）

每篇必须采齐这六样，少两样以上不能动笔。

| # | 类型 | 要求 | 范本示例 |
|---|---|---|---|
| 1 | 可量化动作 A | 带数字的重复动作 | "摁一下，松手，再摁一下"（三回） |
| 2 | 可量化动作 B | 带数字的失败 | "去了六次，第五次才敢进器械区" |
| 3 | 可量化动作 C | 带数字的生活细节 | "八百块，在小票上停了四秒" |
| 4 | 他自己的原话 | 一句，必须是原话不是转述 | "我就想有一件事，跟这个家没关系" |
| 5 | **周围人的原话（要轻）** | 越轻越好，不能是贬低 | "挺好的，别耽误接孩子" |
| 6 | 一个锚点物件 | 能反复出现 | 吉他 |

> **第 5 项是男版和女版最大的不同。**
> 女版要一句"反对"，男版要一句"轻"。轻到读者会替他不平，而他自己说不出什么。

---

## 二、怎么采（三种问法）

**不要问"你怎么想的"**，要问：

1. **"那天具体是怎么弄的？你从头说一遍。"**
   → 拿到动作和数字。人讲流程时会自动吐出细节。

2. **"最难的是哪一次？"**
   → 拿到狼狈段。这一问几乎必出金句。

3. **"这事儿你跟谁说过？他怎么说？"**
   → 拿到第 5 项。
   **追问一句：「他是不是就说了句'挺好'？」** 大多数时候答案是"对，就说了句挺好"。
   如果对方说"没人说过，我没跟人说"——更好，这就是本篇的发现。

> ⚠️ **不要问「你老婆反对吗」。** 这一问会把素材带偏到"家里不支持"，那是最俗的一种中年男人故事。
> 男版真正的材料在"没人管"里，不在"有人拦"里。

**记录规范**：只记名词、动词、数字和原话。**不要记形容词。**

---

## 三、锚点物件清单（选一个，不要贪多）

好的锚点物件满足三条：**小、可重复、有"被随手放下"的意思。**

男版最好的物件，都是**会被搁在一边的东西**——这本身就是内容。

| 物件 | 能承载什么 | 适合的选题 |
|---|---|---|
| **吉他 / 乐器** ⭐最强 | 买了，放下了，又拿起来 | 学一门手艺、捡回年轻时的爱好 |
| **跑鞋** | 花钱了，没穿过几次 | 健身、戒烟、对自己好一点 |
| **车钥匙** | 谁在开车，谁在坐车 | 通勤、独自出门 |
| **工牌** | 你是谁的人 | 辞职、换行、下班 |
| **体检报告** | 还剩多少 | 开始注意身体 |
| **相机** | 拍什么 | 独处、走路、重新看东西 |
| **渔具** | 一个人待着 | 周末、独处 |
| **茶杯 / 保温杯** | 每天重复的那件事 | 上班、习惯 |
| **烟** | 戒掉的东西 | 戒烟、身体 |
| **阳台** | 家里唯一属于他的那一小块 | 独处、自己的地方 |
| **一双旧鞋 / 旧外套** | 舍不得换 | 自己的钱、体面 |

**使用铁律：**
- 全文只选 **1 个**，最多 2 个
- 必须在 **①段出现一次、⑦段再出现一次**
- 出现时**只写动作，不解释含义**

> ✅「他把吉他搁在腿上，左手摁第三根弦，摁了三下，弦没响。」
> ❌「吉他象征着他被搁置了二十年的青春」（解释即死亡）

## 四、三种高级用法

### 1. 用动作代替情绪
> ❌ 他心里挺不是滋味。 → ✅ 他把烟掐了。
> ❌ 他感到一阵轻松。 → ✅ 走到楼下，才把手机掏出来。

**规则：删掉所有"感到 / 觉得 / 心里"开头的句子。**

### 2. 用"算得清的小账"代替抒情
> ❌ 他觉得这钱花得值。 → ✅「八百块，比孩子一节补课费还少。」

**规则：情绪越强的地方，越要写一个具体的数字或物件。**
男版尤其吃这一招——**中年男人不擅长说感受，但极擅长算账。**

### 3. 用"不够体面"的细节建立信任

手抖 / 按不住弦 / 站在浅水区不敢下水 / 被十九岁的小孩叫叔叔 / 贴创口贴继续切菜 / 进了健身房又出来，第二天才进去。

**规则：一篇里至少 2 个让他"不体面"的细节。** 全部体面的主角，读者不会认。

> 男版的"不体面"要选**动身体的**那种，不要选"丢面子"的那种。
> 手抖是好的，被人看不起是坏的——后者会滑向自怜。

## 五、红线

| 红线 | 说明 |
|---|---|
| 不编 | 一个细节编了，整篇可信度都在赔 |
| 不美化 | 不要把"摁不响"改成"弹得挺顺" |
| 不概括 | "他很不容易"是概括；"去了六次"是细节 |
| 不挪用 | 别人身上的细节不能安到他身上 |
| 不写隐私 | 住址、单位全名、孩子学校一律虚化 |
| 不替他抒情 | 素材里没有的感受，一个字都不能加 |
| 要征得同意 | 写真人前问一句"我能写你吗" |

**素材不够时**：宁可输出「补采清单」让用户回去问，也不要填空。这是本技能的硬规则。
