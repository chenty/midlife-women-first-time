# 中年男人的第一次

一个写作技能包。给 AI 装上之后，它能把你手上的一个真人素材，写成一个 **40+ 普通男人做的一件没人当真、也没人反对的小事**。

它不是《中年女人的第一次》改几个字。**技法同源，伤口的位置不一样。**

写给谁看：写 40+ 男性选题的号主。一个人写，没有编辑。

---

## 和女版有什么不同

女版写的是「被拦住的人」：她要考驾照，老公说这钱够买台洗衣机。
男版写的是「被放过的人」：他报了个吉他班，老婆说挺好的，别耽误接孩子。

| | 40+ 女人 | 40+ 男人 |
|---|---|---|
| 反对长什么样 | 明确的拦：「你凭什么」 | 礼貌的放过：「挺好的」「你随意」 |
| 被质疑的 | 许可 | 价值 |
| 最怕写成 | 励志文 | **自怜文** |

一句话：

> **女人到了四十岁，是被拦住的。男人到了四十岁，是被放过的。**
> 被拦住的人有话说，被放过的人说不出话——因为他找不到一个可以怪的人。

这个技能就是把这句"说不出的话"写出来。

---

## 三条硬规矩

1. **白描，不判断。** 只写看见的。删掉所有"感到 / 觉得 / 心里"。
2. **不给圆满结局。** 结尾留白，不许"终于""证明了自己"。
3. **结尾不加引导语。** 不求赞、不求在看、不上价值，只留一个问题。

外加男版独有的一条：

4. **不许自怜。** 写"全世界没有一个懂我的人"，读者不会留言，只会觉得累。
   检验法：念完，读者想说"你挺可怜的"→ 改；想说"这事儿我也有"→ 对了。

## 什么时候用它

- 手上有一个真人的素材，要写成一篇推文
- 稿子写完了，想知道能不能发（17 项自动检查）
- 想不出选题，要从一批素材里挑
- 连着发了三篇，怕读者看出套路
- 标题定不下来，要几个候选

**它写不了什么：** 资讯、教程、观点评论、带货文案。它只干一件事——**把一个人写活。**


## 怎么用

装好之后不用记命令，正常说话就行：

> 写一篇，素材是：我表哥 45 岁，去年买了把吉他，报了班，去了六次课，现在只会按响第三根弦。

> 这篇帮我改一下，我觉得太像在诉苦了。

> 这几个素材帮我排个顺序，哪个先发。

> 帮我看看这篇的标题，多给几个。

### 它会给你什么

1. **一篇成稿**（1100–1200 字）
2. **标题候选**（3–5 个，带推荐理由）
3. **发布前质检报告**（17 项，指出问题在第几段）

### 用之前最好准备这些

- 他多大、做什么的
- 一件他做了、但没人当真的小事
- 周围人的原话——**越轻越好**，"挺好的"比"你不行"有用得多
- 一个能看见的物件：吉他、跑鞋、工牌、体检报告
- 一个"不体面"的细节：手抖、贴创口贴、站在门口不敢进

**给不出这些，它也会写，但写出来会空。**

## 里面有什么

```
SKILL.md                  总纲：男版的伤口在哪 + 工作流
references/
  structure.md            七段骨架（④段是"无声段"，不是"摩擦段"）
  structure-library.md    五种结构，防止每篇一个样
  variation.md            发到第 N 篇怎么不重复
  topics.md               ★ 唯一判据：说出去以后，有人当真吗
  details.md              素材清单、锚点物件、细节红线
  language.md             金句句式、标题公式、结尾提问
  operations.md           评论区怎么回、数据不好怎么查
  examples.md             范本逐段拆解，写作时对照
scripts/
  check_draft.py          发布前质检，17 项
  check_variation.py      查连着几篇有没有撞结构
  new_article.py          拉空骨架，记得加 --gender m
assets/
  skeleton.md             填空版骨架
  sample_pass.md          17 项全过的范本（1132 字）
```

**`scripts/` 和女版是同一份文件**，逐字相同，改一处两边都改。用 `tools/sync_scripts.py --check` 校验。

---

## 一点提醒

- **脚本查得出形，查不出"发现"。** 四问得你自己答：发现是什么、材料凭什么放一起、意义怎么变、结尾如何照亮开头。
- **质检报告不是圣旨。** 它偶尔误报。
- **它没有历史数据基线。** 女版那套阅读/留言率不能直接对标。你发的第一篇，就是你的基线。
