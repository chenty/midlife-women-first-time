# 四十岁去考驾照，教练问她是不是家里要买车

上车第一件事，她把驾驶座往前调，调一下，坐一坐，再调一下。

教练在旁边看了半天，问她："家里要买车啊？"

她摇头。

"那是接送孩子上下学？老公开腻了，把车给你开了？"

她还是摇头。

这是我在驾校练车的第三周，跟我同车的人，是个四十多岁的女人，话不多，手脚慢。我在基层工作十多年，见的人多，她给我的印象最深刻。

教练说，在咱们这个小地方，这把年纪来学车的，十个有九个是家里要用，但她不是。

她孩子今年去外地念大学，家里一下空了。那台车老公开，她坐副驾，坐了二十年。**去哪儿、走哪条路、几点回，从来不归她定。**

有一年正月她回娘家拜年，老公没空去，她拎着东西在路边等车、打第三个电话才约到、车费比平时贵多少。

她决定学车，谁都不接送。

有一回练车间隙，她跟我说了句实在话：**"我就想握一回方向盘，想去哪就去哪，不用被别人牵制。"**

调座椅那天，我在车下看着。她调了三回，才让脚够得着踏板、后背贴实椅背。她坐着愣了一下，说自己坐了二十年车，头一回知道，这个位子是能按自己的腿长调的。

**家里那台车，副驾是她的，座椅永远是别人坐完的那个位置。**

头一回把车开起来，她手心全是汗，车子歪歪扭扭挪出十几米，她自己先笑了。

科二她考了三回。前两回都是倒库压线，第三回才过。教练急了，说她这年纪学得慢；同车的小伙子也笑。她不恼，下车喝口水，接着排号。她跟我说，笨就笨点，慢就慢点，又不是非要跟谁比。

那段时间，我手机上总刷到四十多岁重新活的新闻，留学的、辞职的、一个人自驾的，看着都挺远。她没那些，她就是每周请半天假来练车，但她老公的意思是，学它干啥，又不买车，这钱够买台洗衣机；孩子不用她接，出门有他开，一个女人家逞什么能。

他没硬拦，就是不理解，放着舒坦日子不过，折腾个啥。

这话不算坏，周围不少人都这么想。把钱和时间省下来，给家里添件东西，省心，也没人笑话。

她偏不。她算的是另一笔：钱省下来，东西是家里的；时间搭进去，日子还是别人替她定的。都这把年纪了，她想有一样东西，是自己学的，哪怕学出来用不上。

这条路也不轻松。请假、被人嫌慢、考三回才过的难堪，都是真的；到现在她科三还没考，车也没买，学出来到底开不开得上，她自己也不知道。

她跟我说过一句话，我记到现在。**她说人这一辈子，给家里花的钱都叫应该，轮到给自己花，才叫浪费。**

我没夸她励志，她也不励志。考完本她也没有自驾去远方。

我只看见她每次上车，都把座椅往前调那么两格，调到自己的位置，坐踏实了，才把钥匙拧开。

后视镜里映出一张中年女人的脸，不慌，也不躲。

那一小段练车场，**方向盘在她手里，前面的路，她自己打方向。**

你心里是不是也有一件想学、又怕没用的事？
